# LocoRide 🚕

LocoRide is a local taxi platform connecting customers
with independent drivers.

## Vehicle Types

- 🏍️ Bike
- 🛺 Auto
- 🚗 Car

## Platforms

- Customer App
- Driver App
- LocoRide Admin

## Main Features

- Ride booking
- Fare calculation
- Driver matching
- Live ride tracking
- Customer PIN verification
- Vehicle photo verification
- Online and cash payments
- Ratings and reviews
- Driver earnings
- Admin management

## Project Status

🚧 LocoRide is currently under development.
